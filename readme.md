VexDice 🎲

一个运行在 Minecraft 原版中的跑团掷骰机器人，灵感来自 SealDice。

---

✨ 项目简介

VexDice 使用 Minecraft 1.20.5+ 原版数据包 的命令系统（宏、/random、计分板、存储）构建了一个功能完整的骰子核心。无需任何 Mod，无需服务端插件，丢进 datapacks 文件夹就能拥有一个交互式的跑团助手。

你可以通过点击聊天栏中的按钮来设定骰子数量与面数，然后一键掷出结果。后续还会逐步加入加值、优势/劣势、角色卡、对抗检定等经典 TRPG 规则。

---

📦 安装

1. 确保你的 Minecraft 版本 ≥ 1.20.5（Java 版）
2. 下载本数据包，将 vexdice 文件夹放入存档的 datapacks/ 目录
3. 在游戏中执行 /reload 或重新进入存档
4. 在聊天栏输入以下命令以获取菜单（具体触发器名请查看下文）：
   ```
   /trigger vex.input.val
   ```
   （或使用已绑定的快捷命令，首次使用可能需要启用计分板，请根据游戏提示操作）

---

🕹️ 使用方法

目前通过一套图形化点击界面完成掷骰：

1. 玩家使用一个快捷指令（默认由某个初始化函数绑定）打开面板
2. 面板显示当前掷骰表达式，如 3d6
3. 点击 [掷骰次数] 或 [骰子面数] 切换调整目标
4. 使用 [-1] [+1] 等按钮修改当前项的值
5. 点击 [[ 当前值 ]] 执行掷骰
6. 结果以 Actionbar（快捷栏上方）和 chat 消息形式反馈，包含总和与每个骰子点数（开发中）

常用表达式示例：

· 1d20 → D20 检定
· 3d6 → 伤害或属性生成
· 后续将支持 3d6+2、d% 等

🗂️ 项目结构

```
vexdice/
└── data/
    ├── minecraft/
    │   └── tags/
    │       └── function/          # tick、load 函数标签
    └── vexdice/
        └── function/
            ├── core/              # 掷骰引擎（roll, roll_loop 等）
            └── sr_input/          # 输入处理与 UI 渲染
                ├── chat/          # 聊天栏交互逻辑
                └── visible/       # 可视面板（待扩展）
```

核心逻辑集中在 core/roll 和 core/roll_loop，它们通过宏递归实现批量随机数生成，完全不依赖实体。
